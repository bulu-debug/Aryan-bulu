# Ferdinand Aryan Bulu — Portfolio

Website portofolio pribadi menggunakan HTML, CSS, JavaScript, dan Bootstrap 5.3.

## Struktur
- `index.html` — halaman utama
- `css/` — stylesheet utama, responsif, dan animasi
- `js/` — interaksi, animasi, navbar, dan galeri
- `assets/images/` — foto profil, dokumentasi pengalaman, dan screenshot proyek
- `assets/icons/` — logo aplikasi dan teknologi untuk bagian Skills

## Logo Skills
Simpan sembilan file PNG berikut ke `assets/icons/`:
`excel.png`, `word.png`, `powerpoint.png`, `canva.png`, `capcut.png`, `html.png`, `css.png`, `javascript.png`, `bootstrap.png`.

## Menjalankan
Buka `index.html` menggunakan browser. Untuk publikasi gratis, unggah folder proyek ke repository GitHub lalu aktifkan GitHub Pages dari Settings → Pages.
